# [ADR-001] 지도는 네이버 지도 SDK, 주유소·유가는 오피넷 API

- **날짜:** 2026-11-06
- **상태:** 채택

## 배경

나누길은 Pleos Connect(Android Automotive OS 기반) 위에서 돈다. 지도와 관련해 필요한 기능은 네 가지다.

| # | 기능 | 필요한 것 |
| --- | --- | --- |
| R1 | 일행 차량 위치·속도·도착 예정 시간을 지도에 표시 | 앱 안에 그리는 지도 + 마커 |
| R2 | 연료 부족 차량 감지 | 연료·배터리 잔량 (Pleos Vehicle SDK) |
| R3 | 주변 주유소를 찾아 모든 차량 경로에 합류 지점으로 추가 | 주유소 검색 + 내비 경유지 추가 |
| R4 | 주유비를 실제 유가로 계산해 1/N 정산 | 주유소별 유가 |

조건은 세 가지였다. **무료**일 것, **국내 자동차 경로**가 될 것, **AAOS에서 동작**할 것. 지도 업체는 가능한 한 **하나로 통일**한다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **네이버 지도 SDK** | 지도 표시 월 600만 건 무료, 국내 POI·도로 데이터 최상, Directions(경유지 5/15개) 제공, 한국어 문서·데모 풍부, Google Play 서비스 의존 없음 | 지역 검색 API가 키워드 검색만 되고 한 번에 5개 → 좌표 반경 주유소 검색 불가 |
| 카카오맵 SDK | 지도 SDK 일 30만 건, 카테고리 검색으로 주유소 검색 가능 | 무료 쿼터가 계정의 첫 앱에만 적용, 카카오모빌리티 내비 기능은 상업 이용 시 제휴 필요·타사 지도 위 표시 불가 |
| 구글 Maps / Navigation SDK | AAOS 공식 지원 | 국내 자동차·도보 길안내 미제공, Maps SDK가 Google Play 서비스에 의존 |
| 티맵 API | 경로 반경 주유소 검색, 국내 내비 데이터 최고 수준 | 무료 플랜 유가 정보 일 1건, 지도 무료 한도가 네이버보다 작음 |
| Mapbox / MapLibre(OSM) | 무료 시작 가능, 오픈소스 | 국내 도로·POI 정확도 낮음, 국내 길찾기 사실상 불가 |
| **오피넷 API (한국석유공사)** | 좌표 반경 5km 주유소 + **실제 판매가격**, 무료 일 1,500건, 공공 데이터라 지도 업체와 무관 | 좌표계가 KATEC이라 변환 필요, 반경 최대 5km |

## 결정

**지도는 네이버 지도 SDK 하나로 통일하고, 주유소 검색과 유가는 오피넷 API로 받는다.**

| 역할 | 사용 |
| --- | --- |
| 지도 화면, 일행·주유소 마커 (R1) | 네이버 지도 Android SDK 3.24.0 |
| 주변 주유소 + 유가 (R3, R4) | 오피넷 `aroundAll.do` (반경 내 주유소) |
| 연료 잔량, 주행거리 (R2, R4) | Pleos Vehicle SDK |
| 내 차 경로에 합류 주유소 추가 (R3) | Pleos NaviHelper SDK `addWaypoint` + `requestReRoute` (다음 작업) |
| 구간 거리·통행료 추정 (R4) | 네이버 Directions 5 (필요 시, 서버에서 호출) |

이유:

1. **지도 업체가 하나다.** 오피넷은 지도가 아니라 공공 유가 데이터라서, 네이버 하나만 지도로 쓰는 원칙이 그대로 유지된다. 카카오·티맵을 섞지 않으니 각 사 약관(타사 지도 위 표시 금지 등)을 신경 쓸 일이 없다.
2. **R3과 R4를 한 번에 푼다.** 오피넷은 주유소 위치와 *그 주유소의 오늘 가격*을 같이 준다. 합류 주유소를 고를 때 최저가 순으로 보여 줄 수 있고, 정산의 `주행 거리 ÷ 연비 × 유가`에서 유가를 실제 값으로 넣을 수 있다.
3. **비용 0원.** 공모전·시연 규모에서 네이버(지도 월 600만 건), 오피넷(일 1,500건) 모두 무료 한도 안이다.
4. **경로 안내는 직접 만들지 않는다.** 실제 턴바이턴 안내는 Pleos 내장 내비가 하고, 우리는 NaviHelper로 경유지만 넣는다. 네이버 Directions는 경로를 *계산*할 뿐 차 내비를 바꾸지 못하므로 이 역할에 쓰지 않는다.

## 영향

- **KATEC 좌표 변환이 필요하다.** 오피넷은 위경도가 아닌 KATEC 좌표만 받으므로 `core/geo/KatecConverter`를 만들었다. 같은 정의를 다른 알고리즘(Krüger 급수)으로 계산한 값과 0.1m까지 일치하고, 왕복 오차는 1cm 미만이다. 오피넷 응답 좌표와는 약 10m 이내로 맞는다.
- **키 관리.** 네이버 Client ID와 오피넷 키는 `local.properties`에 두고 `BuildConfig`로 주입한다(커밋 금지). 시연용으로 앱에서 오피넷을 직접 부르지만, 서버가 생기면 서버를 거쳐 호출해 키를 숨긴다.
- **반경 5km 제한.** 고속도로처럼 주유소가 드문 구간에서는 결과가 없을 수 있다. 그때는 경로 위 여러 지점에서 나눠 조회하거나 휴게소 주유소를 우선 조회하는 방식으로 보완한다.
- **지도와 실제 안내가 다른 엔진이다.** 우리 화면(네이버)은 "일행 위치 보기"용이고, 경로선은 내장 내비가 그린다. 두 화면의 길이 미세하게 다를 수 있다.
- **검증할 것.** Pleos 에뮬레이터에서 네이버 지도 렌더링과 인증이 되는지 가장 먼저 확인한다. 실패하면 카카오맵 SDK로 교체하는 것이 1순위 대안이다.
